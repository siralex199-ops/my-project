# ⚽ پیش‌بین فوتبال

برنامه‌ای برای **پیش‌بینی بازی‌های فوتبال** بر پایه‌ی مدل آماری **دیکسون-کولز** — بدون هیچ کتابخانه‌ی بیرونی، فقط پایتون ۳.۱۰+ و کتابخانه‌ی استاندارد.

روی **۴۵ هزار بازی واقعی** از ۹ لیگ اروپا (لیگ برتر انگلیس، چمپیونشیپ، لالیگا، سری آ و سری بی ایتالیا، بوندس‌لیگا، لیگ ۱ فرانسه، اردیویزی و لیگ پرتغال) آموزش می‌بیند و خروجی می‌دهد:

- احتمال **برد میزبان / مساوی / برد میهمان** (۱X۲)
- **گل انتظاری** هر تیم و محتمل‌ترین نتایج دقیق
- بازارهایی مثل **بالای ۱.۵ / ۲.۵ / ۳.۵ گل**، **هر دو گل می‌زنند** و **شانس دوگانه**
- **ماتریس کامل احتمال** همه‌ی نتایج
- **شبیه‌سازی مونت‌کارلوی ادامه‌ی فصل**: شانس قهرمانی، حضور در پنج تیم برتر و سقوط
- رابط وب فارسی (راست‌به‌چپ) + رابط خط فرمان

```bash
# ۱) رابط وب

#   → http://localhost:8000

# ۲) رابط خط فرمان
```

## مدل چطور کار می‌کند؟

برای هر تیم دو پارامتر یاد گرفته می‌شود: **قدرت حمله** (attack) و **ضعف دفاع** (defence).
میانگین گل‌های هر تیم در یک بازی از توزیع پواسون می‌آید:

```
λ_میزبان = exp( حمله‌ی میزبان + دفاع‌ی میهمان + مزیت میزبانی )
λ_میهمان = exp( حمله‌ی میهمان + دفاع‌ی میزبان )
P(نتیجه = x-y) = Pois(x; λ_میزبان) × Pois(y; λ_میهمان) × τ(x, y)
```

سه نکته‌ی مهم که مدل را از یک پواسون ساده جدا می‌کند:

1. **اصلاح دیکسون-کولز (τ)** — نتایج کم‌گل (۰-۰، ۱-۰، ۰-۱، ۱-۱) در واقعیت بیشتر از حالت مستقل دو پواسون رخ می‌دهند؛ τ این همبستگی را مدل می‌کند.
2. **وزن‌دهی زمانی** — هر بازی با نیمه‌عمر ۳۶۵ روز وزن می‌گیرد، پس فرم اخیر تیم‌ها مهم‌تر از نتایج سه سال پیش است.
3. **تنظیم L2 (ridge)** — از بیش‌برازش روی تیم‌هایی که بازی کمی دارند (مثلاً تیم‌های تازه‌صعودکرده) جلوگیری می‌کند.

پارامترها با بیشینه‌سازی وزن‌دار درست‌نمایی (weighted MLE) و بهینه‌ساز **Adam** با گرادیان تحلیلی برازش می‌شوند — پیاده‌سازی کامل در `football_predictor/model.py` و بدون numpy.

## کیفیت مدل (اعتبارسنجی)

روش: آموزش روی داده‌های قبل از هر فصل، آزمایش روی همان فصل (walk-forward) — مجموعاً ۹٬۴۳۷ بازی از سه فصل و ۹ لیگ:

| معیار | مدل دیکسون-کولز | مدل ساده (نرخ پایه) |
|---|---|---|
| دقت پیش‌بینی ۱X۲ | **۴۹.۷٪** | ۴۳.۲٪ |
| Log-loss (کمتر بهتر) | **۱.۰۰۷۸** | ۱.۰۷۶۱ |
| امتیاز بریر (کمتر بهتر) | **۰.۶۰۳** | ۰.۶۵۱ |

برای مقایسه: ضرایب بوک‌می‌کرها معمولاً Log-loss حدود ۰.۹۷ تا ۱.۰۰ دارند؛ یعنی این مدل — که فقط از نتایج گذشته استفاده می‌کند و هیچ خبر، مصدوم یا ترکیب تیمی نمی‌بیند — به عملکرد بازار نزدیک است.

بازتولید گزارش:

```bash
python3 scripts/backtest.py            # → data/backtest.json (در صفحه‌ی «درباره مدل» نمایش داده می‌شود)
```

## داده‌ها

- منبع: مخزن متن‌باز [`openfootball/football.json`](https://github.com/openfootball/football.json) — نتایج بازی‌های ۲۰۱۰ تا امروز.
- خروجی پردازش‌شده در `data/matches.csv` (~۴۵ هزار بازی) و `data/teams.json` (نام فارسی/انگلیسی ۲۸۵ تیم) نگهداری می‌شود.
- برای بازسازی/به‌روزرسانی داده‌ها:

```bash
python3 scripts/build_dataset.py                       # دانلود خودکار از GitHub
python3 scripts/build_dataset.py --source /path/to/football.json
```

اسکریپت، نام‌های مختلف یک باشگاه (`Arsenal FC` / `Arsenal`، `FC Bayern München` / `Bayern München`، …) را یکسان‌سازی می‌کند.

### جدول رسمی لیگ‌ها (ورزش۳)

برنامه دو جدول دارد: **جدول رسمی** (خوانده‌شده از varzesh3.com با تاریخ به‌روزرسانی خود سایت) و **جدول مدل** (محاسبه‌شده از نتایج موجود در دیتاست). در صفحه‌ی «جدول و قدرت» با کلید بالای جدول می‌توانید بین این دو جابه‌جا شوید.

جدول‌های رسمی واردشده (تا ۲ نوامبر ۲۰۲۶):

| لیگ | شناسه در ورزش۳ | تیم | آخرین به‌روزرسانی |
|---|---|---|---|
| لیگ برتر ایران (خلیج فارس) | league/6 | ۱۸ | ۹ آبان ۱۴۰۵ |
| لیگ برتر انگلیس | league/3 | ۲۰ | ۹ آبان ۱۴۰۵ |
| لالیگا اسپانیا | league/2 | ۲۰ | ۹ آبان ۱۴۰۵ |
| بوندسلیگا آلمان | league/1 | ۱۸ | ۱۰ آبان ۱۴۰۵ |
| سری آ ایتالیا | league/4 | ۲۰ | ۱۱ آبان ۱۴۰۵ |
| لیگ ۱ فرانسه | league/5 | ۱۸ | ۱۰ آبان ۱۴۰۵ |
| اردیویسه هلند | league/7 | ۱۸ | ۱۰ آبان ۱۴۰۵ |
| لیگ برتر پرتغال | league/55 | ۱۸ | ۱۱ آبان ۱۴۰۵ |

فهرست کامل لیگ‌ها با شناسه‌ی صفحه‌ی ورزش۳ و وضعیت (واردشده / در انتظار) در `data/leagues_varzesh3.json` است.

به‌روزرسانی یک جدول:

```bash
python3 scripts/import_standings.py --league en.1 --file /tmp/pl.md --date 2026-10-31 \
    --url "https://www.varzesh3.com/football/league/3" --expected 20
```

**لیگ‌های خارج از دیتاست مدل** (مثل لیگ برتر ایران) هم پشتیبانی می‌شوند؛ کافی است `--title` و `--allow-unknown` بدهید:

```bash
python3 scripts/import_standings.py --league ir.1 --title "لیگ برتر ایران (خلیج فارس)" \
    --file /tmp/iran.md --date 2026-10-31 --expected 18 --allow-unknown
```

این لیگ‌ها در فهرست برنامه با حاشیه‌ی خط‌چین نمایش داده می‌شوند، جدول رسمی‌شان کامل کار می‌کند و برای آن‌ها پیام «مدل محاسبه نمی‌شود» نشان داده می‌شود.

نکات:
- ورودکننده اگر دو ردیف به یک تیم نگاشت شوند **کل ورود را رد می‌کند** (نام را با `--map "نام سایت=کلید"` مشخص کنید).
- هر جدول با معیارهای درونی چک می‌شود (مجموع گل زده = خورده، برد = باخت، مجموع بازی زوج)؛ تست `tests/test_standings.py` همه‌ی جدول‌های واردشده را همین‌طور می‌سنجد.
- کسر امتیاز (مثل ملوان در لیگ ایران) در فیلد `note` همان لیگ ثبت می‌شود.

### ثبت نتیجه‌ی بازی‌های تازه

نتیجه‌هایی که در دیتاست نیستند (یا بازی‌هایی که تازه تمام شده‌اند) را در `data/manual_results.csv` ثبت کنید. این فایل بعد از بازسازی دیتاست هم حفظ می‌شود و روی نتایج پایه اعمال می‌شود:

```bash
python3 scripts/add_result.py --league es.1 --home "الچه" --away "والنسیا" --score 0-1 --date 2026-11-01
```

پس از ثبت، مدل و جدول و پیش‌بینی‌های بعدی به‌طور خودکار به‌روز می‌شوند (سرور وب را دوباره اجرا کنید تا مدل بازبرازش شود).

## ساختار پروژه

```
football_predictor/
  dataset.py     بارگذاری بازی‌ها، تیم‌ها و یافتن تیم از نام فارسی/انگلیسی

  predictor.py   لایه‌ی لیگ: بازی‌های پیش‌رو، جدول، قدرت تیم‌ها، شبیه‌سازی فصل

web/
  server.py      سرور HTTP و API (فقط کتابخانه استاندارد)

data/            دیتاست پردازش‌شده + نتایج اعتبارسنجی
scripts/         build_dataset.py، backtest.py
tests/           تست‌های واحد (unittest)
```

## API

سرور وب این مسیرها را ارائه می‌دهد (همه JSON و بدون کلید):

| مسیر | کار |
|---|---|
| `GET /api/leagues` | فهرست لیگ‌ها، فصل جاری، تعداد بازی پیش‌رو |
| `GET /api/fixtures?league=en.1&limit=24` | پیش‌بینی بازی‌های پیش‌رو |
| `GET /api/predict?league=en.1&home=arsenal&away=chelsea` | پیش‌بینی کامل یک بازی (شامل ماتریس احتمال) |
| `GET /api/table?league=es.1` | جدول لیگ |
| `GET /api/power?league=it.1` | رتبه‌بندی قدرت مدل |
| `GET /api/simulate?league=de.1&runs=1500` | شبیه‌سازی مونت‌کارلوی ادامه فصل |
| `GET /api/meta` | اطلاعات داده و نتایج اعتبارسنجی |

مثال:

```bash
curl "http://localhost:8000/api/predict?league=en.1&home=arsenal&away=chelsea"
```

## محدودیت‌ها

- مدل فقط از **نتایج گذشته** استفاده می‌کند: مصدومیت، نقل‌وانتقالات، خستگی و انگیزه را نمی‌بیند.
- تیم‌های تازه‌صعودکرده تاریخچه‌ی کمی در بالاترین سطح دارند و پیش‌بینی‌شان نامطمئن‌تر است.
- دیتاست یک **عکس لحظه‌ای** است؛ برای به‌روزرسانی `scripts/build_dataset.py` را دوباره اجرا کنید.
- این پروژه ابزار آماری و آموزشی است و **توصیه‌ی شرط‌بندی نیست**. پیش‌بینی احتمالاتی هیچ‌گاه قطعی نیست و شرط‌بندی ریسک مالی جدی دارد.
